Prisma 3D Lite · Getting Started

A quick introduction to the main parts of the editor. These guides are built into this menu as a starting point.

1. Create and navigate a scene

  • Choose New Project to open a clean scene.
  • Use the viewport controls to orbit, pan, and zoom around your scene.
  • Use the object tools to add primitives, cameras, lights, and other scene elements.

2. Import and organize models

  • Use the import controls in the editor to bring supported model files into your scene.
  • Select an object to edit its transform and properties.
  • Save reusable objects in the Saved Models library when available.

3. Animate

  • Select an object or rigged model, move the playhead, and record keyframes.
  • Use the timeline to adjust timing and preview your animation.
  • Play the timeline before exporting to check the motion.

4. Save and render

  • Your current project is autosaved in this browser while you work.
  • Use Saved Projects to reopen, rename, or manage saved work.
  • Use the export controls to create a video when your scene is ready.

More detailed tutorials can be added as the editor's tools evolve.

Import 3D model

Sketchfab / MediaFire: download the model from the site, then choose the downloaded file here. Supported formats: GLB, GLTF, FBX, OBJ, STL, PLY and Prisma packages (.prisma, which include their own textures). GLB is best because it usually includes textures. OBJ may need its MTL and texture files alongside it. A Sketchfab or MediaFire web page link is not itself a model file.

Direct URL loading is limited to GLB/GLTF files hosted where browser access is allowed. If the link fails, download the model first and import it from your device.

Object hierarchy

Select multiple objects using the checkboxes. The active object (highlighted) becomes the parent; the other selected objects become its children. Drag an object onto another object to parent it. Select parented objects and use Unparent Selected to detach them while keeping their world position.
