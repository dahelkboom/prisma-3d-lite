Import 3D model

Sketchfab / MediaFire: download the model from the site, then choose the downloaded file here. Supported formats: GLB, GLTF, FBX, OBJ, STL, PLY and Prisma packages (.prisma, which include their own textures). GLB is best because it usually includes textures. OBJ may need its MTL and texture files alongside it. A Sketchfab or MediaFire web page link is not itself a model file.

Direct URL loading is limited to GLB/GLTF files hosted where browser access is allowed. If the link fails, download the model first and import it from your device.

Exports the selected model as a binary GLB download. The exporter reads the model without reparenting it or changing the active scene. Check your browser Downloads folder or choose Save to Files when offered.

Rigging / Pose

Select a rigged model to reveal its bones as white handles. FK rotates individual joints; IK lets you move a selected bone target and solve its parent chain.

1.0×

Create a root bone on the selected model, then select a bone and add connected child bones. These create and animate a skeleton hierarchy; they do not automatically paint skin weights onto an unrigged mesh.

Select a model to enable bone creation.
